# Tu Comida Compilada

Repositorio oficial del proyecto web Tu Comida Compilada.

______________________________________________________________________

## Sobre el Proyecto

Nombre del equipo: Tu Comida compilada

Disfruta de ingredientes frescos, recetas preparadas al momento y el mejor sabor
en cada bocado. Haz tu pedido de forma rápida y recibe tus comidas favoritas sin
salir de casa.

Esta plataforma permite a los usuarios explorar un menú digital interactivo,
filtrar platos por categoría y gestionar un carrito de compras dinámico en
tiempo real.

______________________________________________________________________

## Funcionalidades Principales

- Menú Dinámico: Renderizado de productos a través de JavaScript a partir de una
  lista de datos centralizada.
- Filtros de Menú: Clasificación por categorías como hamburguesas, pizzas,
  bebidas y postres.
- Carrito de Compras:
  - Adición y eliminación de productos.
  - Ajuste de cantidades por artículo.
  - Cálculo automático de subtotal, costo de envío y total general.
- Diseño Adaptable: Interfaz ajustada para navegación en dispositivos móviles,
  tabletas y computadoras.
